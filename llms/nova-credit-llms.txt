# Nova Credit

> Nova Credit is a fintech consumer-credit-data platform that provides a single
> API surface to access unified consumer credit data from multiple sources —
> international credit bureaus, bank-transaction aggregators, payroll systems,
> and automated document data (26+ data sources). Its products let lenders and
> financial institutions underwrite newcomers and thin-file applicants, verify
> income, and assess affordability.

## Products
- [Credit Passport](https://www.novacredit.com/credit-passport): Approve qualified newcomers using translated international credit data (API v4).
- [Cash Atlas](https://www.novacredit.com/cash-atlas): Bank-transaction-based cashflow underwriting (API v2).
- [Income Navigator](https://www.novacredit.com/income-navigator): Automated income verification with fraud detection (API v2).
- [Eligibility Compass](https://www.novacredit.com/eligibility-compass): Income and asset verification for affordable housing (API v1).
- [Platform](https://www.novacredit.com/platform): Unified infrastructure across all products.

## APIs
- Production base URL: https://api.novacredit.com
- Sandbox base URL: https://api.sandbox.novacredit.com
- Auth: HTTP Basic (clientId:secretKey) to mint a 5-minute Bearer accessToken; report payloads are JWE (RSA-OAEP-256) encrypted.
- JWKS: https://api.novacredit.com/connect/jwkset
- Webhooks: status callbacks POST a report publicToken to your endpoint.
